COMO SUBSTITUIR NO GITHUB PELO NAVEGADOR

1. Faça um backup do repositório atual.
2. Apague os arquivos do React/Vite/TypeScript da raiz atual:
   - index.html
   - vite.config.js
   - tsconfig.json
   - tsconfig.app.json
   - tsconfig.node.json
   - ARQUIVOS-ALTERADOS.txt
   - README-REACT-HOME-PRONTUARIO.md
3. Dentro de src, apague tudo, mas depois envie o novo src/worker.js deste pacote.
4. Extraia este projeto.
5. No GitHub, use Add file > Upload files.
6. Arraste TODO o conteúdo extraído para a raiz do repositório.
7. Confirme o commit na branch main.

O projeto tem menos de 100 arquivos e pode ser enviado em uma única etapa pelo navegador.

CONFIGURAÇÃO DO CLOUDFLARE

Comando da build: deixar VAZIO
Comando de implantação: npx wrangler deploy
Comando da versão: npx wrangler versions upload
Diretório raiz: /
Branch de produção: main

IMPORTANTE
- Não use npm run build.
- Não use pasta dist.
- O wrangler.toml publica diretamente a pasta public.
- O banco D1 está configurado com o binding DB.
